# assets/ · 设计与素材

这里放**不参与构建逻辑**的静态素材：设计稿导出、图标源文件、话术截图、评测报告附件。
应用实际使用的运行时静态资源在 `public/`（例如 `public/icon.svg`）。

## 设计基调（与 `src/app/globals.css` 保持一致）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--background` | `oklch(0.984 0.006 84)` | 页面底色，暖白 |
| `--foreground` | `oklch(0.245 0.016 62)` | 正文，深棕灰 |
| `--primary` | `oklch(0.628 0.152 52)` | 焦糖橙，只用于需要行动的地方 |
| `--border` | `oklch(0.902 0.01 80)` | 分隔线与卡片描边 |
| `--radius` | `0.75rem` | 卡片圆角 |

## 约束

- 不做营销 Hero，首屏直接是运营指标；
- 状态一律「图标 + 文字」，颜色只做辅助；
- 卡片不嵌套卡片，分组用分隔线与小标题；
- 图标统一使用 `lucide-react`，不手绘复杂 SVG。
